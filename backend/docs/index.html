My Recipe App Backend Documentation

A progressive Node.js framework for building efficient and scalable server-side applications.

Description

The backend application is designed to support various functionalities required for modern web applications, including user authentication, real-time updates, and data management. Using NestJS, we have structured the application into modules that encapsulate related functionality, promoting clean code practices and scalability. MongoDB's flexible schema design allows for efficient storage and retrieval of data, while Socket.IO provides the necessary tools for real-time communication, enhancing the user experience with live updates and interactions.

Key features of this backend include:

  • Authentication and Authorization: Secure user authentication and authorization mechanisms using JWT and bcrypt.
  • Real-Time Communication: Real-time updates and notifications using Socket.IO.
  • Data Management: Efficient data storage and retrieval with MongoDB, including CRUD operations and complex queries.
  • Scalability: Modular design allows for easy extension and maintenance of the application.

Installation 


# Clone the repository
$ git clone https://github.com/your-repo/backend.git

# Navigate into the project directory
$ cd backend

# Install dependencies
$ npm install

# Create a .env file and add your environment variables
$ echo "MONGO_URI=mongodb://localhost:27017/your-database" >> .env
$ echo "SOCKET_IO_URL=http://localhost:3000" >> .env

# Run the application
$ npm run start:dev

Running the App 


# Development mode
$ npm run start:dev

# Production mode
$ npm run start:prod

# Unit tests
$ npm run test

# End-to-end tests
$ npm run test:e2e

# Test coverage
$ npm run test:cov
